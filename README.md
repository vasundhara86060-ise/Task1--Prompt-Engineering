# AI Website Copy Generator for Local Businesses

An AI-powered web application that generates professional and website-ready content for local businesses such as cafés, salons, clinics, and agencies. The project helps users quickly create homepage copy, service descriptions, and CTA content based on business type and tone preference.

---

## 🚀 Features

* Generate homepage hero content
* Create About / Value Proposition sections
* Generate Services section content
* Create strong CTA content
* Multiple business type support
* Tone customization
* Responsive and clean UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

### AI Tools

* ChatGPT
* Claude
* Gemini
* Framer AI

---

## ⚙️ How It Works

1. Enter business details
2. Select business type and tone
3. Add services and location
4. Click **Generate Website Copy**
5. Get AI-generated website content instantly
